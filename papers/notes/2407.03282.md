# 2407.03282 — LLM Internal States Reveal Hallucination Risk Faced With a Query (Ji, Chen, Ishii, Cahyawijaya, Bang, Wilie, Fung; HKUST CAiRE)

Read depth: MEDIUM (method, results, appendix; all chunks read).

## Research question
Can an LLM's internal states on the *query alone* (before any response is generated) estimate (1) whether the query was seen in training data and (2) whether the model's eventual response will hallucinate?

## Method / architecture
- Formulation: h = E(I_{θ,q}; D_θ), estimator E trained on (internal state, label) pairs for the same LLM that generates responses.
- Input x_q = activation of the **last query token** at a chosen layer (default last layer).
- Estimator: Llama-style gated MLP, H = down(up(x_q) × SiLU(gate(x_q))); input dim 4096, hidden 11008 (matched to Llama2-7B). Beats a standard MLP (e.g. Dialogue F1 74.33 vs 70.22).
- Preliminary analysis: mutual-information feature selection picks top-8 neurons of last layer; t-SNE shows separation of hallucinating vs faithful queries.
- Token attribution: Grad-CAM-style gradients of input embeddings through LLM+estimator; unfamiliar named entities get highest contribution.
- Training: 10 epochs, batch 128, lr 1e-5, AdamW + linear schedule, 1 A800.

## Models
Llama2-7B (main); Mistral-7B internal states used to predict Llama2's hallucination (cross-model transfer).

## Datasets
- Seen/unseen: BBC news 2020 (seen) vs 2024 (unseen) from LatestEval; query "Tell more details about the news: {news_title}"; length/semantic matched with `sentence-transformers/all-mpnet-base-v2`.
- Hallucination risk: 15 NLG task categories, >700 datasets from Super-Natural Instructions (full list in Table A2; e.g. QA 207 datasets, Translation 394, Program Execution 90). Sizes per split not given.
- Labels: response is faithful (1) if NLI (HF `MoritzLaurer/mDeBERTa-v3-base-xnli-multilingual-nli-2mil7`) = entailment AND Rouge-L and QuestEval both above median; hallucinated (0) if NLI = contradiction/neutral AND both below median; others discarded. No human labels.
- OOD test: ANAH (English subset) for QA.
- Generation max length is only 50 tokens (inference timing section) — i.e. short responses.

## Probe design
Last token of query; layer sweep at layers 1 / 16 / 32 (of 32) — deeper is better; gated MLP (non-linear); binary classification. Appendix: regression on continuous Rouge-L / NLI-prob / QuestEval targets (absolute, min-max normalized, rank) measured by RMSE; absolute value is easiest, rank hardest.

## Metrics
F1, Accuracy (classification); RMSE (regression variants); inference time per sample.

## Key numbers
- Seen vs unseen: F1 80.28%, Acc 80.24%.
- Hallucination risk: average accuracy 84.32% across 15 tasks; best Number Conversion F1 94.04 / Acc 96.00; weakest Translation F1/Acc 76.90. Baselines (zero-shot prompt, ICL prompt) overconfident (recall ~99% predicting "can answer"); PPL threshold varies (Translation F1 33.73, Data-to-Text F1 88.28).
- Layer depth (Fig. 4): F1 rises from early (layer 1: ~40–83 depending on task) through intermediate (16: ~73–90) to deep (32: ~74–94); contrasts with Azaria & Mitchell where middle layers were best.
- Cross-model (Mistral states → Llama2 hallucination): QA 80.46 vs 82.37 F1; Summarization 83.63 vs 88.08; small drop.
- Cross-task generalization weak: train QA → test Translation F1 51.34; train Translation → test QA F1 20.45; within-task unseen: QA 64.79, Translation 74.03. ANAH OOD QA: F1 78.56, Acc 78.83.
- Cost: internal-state estimator 0.05 s/sample vs PPL 1.35 s, NLI 3.4 s, QuestEval 10.25 s; generation 3.37 s (50 tokens).

## Limitations
- Only Llama2-7B (plus Mistral transfer); automatic labels only, no human eval; query-only (no response context) — authors note trade-off vs. methods that see the response.
- Responses are very short (≤50 tokens), so "forecasting" horizon is trivially short; no analysis vs. position/horizon.
- Labels drop ambiguous middle cases (median-based), inflating separability.
- Weak cross-task transfer.

## Relevance to observer/forecasting hypothesis
- Represents the **"direct probe at t=0"** baseline: a single-position (last prompt token), single-layer, MLP probe predicting a future response-level outcome. The observer hypothesis predicts this kind of probe should degrade as the event moves further into a long response; this paper never tests long horizons, which leaves room for the proposed work.
- Probe-design takeaways for baselines: last-layer > mid-layer for this outcome; gated (SwiGLU) MLP > plain MLP — use a SwiGLU probe as a fair, strong baseline head.
- Weak cross-task generalization suggests evaluating the observer in- and cross-task; trajectory-memory features may or may not transfer better.
- Label construction recipe (NLI + Rouge-L + QuestEval, median thresholds) is a cheap way to create response-level attribute labels, but for long-form you would need span-level timing (first hallucinated span position) to define event times for a hazard model — this paper only provides a binary end-of-response label (equivalent to a fully censored/no-timing outcome).
- No survival / hazard / multi-scale components to borrow.
