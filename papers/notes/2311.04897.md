# 2311.04897 — Future Lens: Anticipating Subsequent Tokens from a Single Hidden State (Pal, Sun, Yuan, Wallace, Bau; 2023)

## Research question
Given one hidden state h^l_T (layer l, position T), how well can we predict the model's tokens at T+2, T+3, T+4 (N = 1..3 beyond next-token N = 0)?

## Method / architecture (four decoders, all from a single state)
1. Direct vocabulary prediction: linear g_theta: R^4096 -> R^50400 logits for y_{T+N} (softmax).
2. Linear model approximation ("HS"): linear f_theta(h^l_T) ≈ h^L_{T+N} (final-layer future hidden state), decoded with frozen LM head (tuned-lens style but across positions).
3. Fixed-prompt causal intervention: transplant h^l_T into the last-token position at layer l of a generic prompt (e.g., "Hello! Could you please tell me more about \"", "The multi-tokens present here are \"", ...), let the model continue, compare future predictions (Eqs. 7-9).
4. Learned-prompt causal intervention (main method, "Future Lens"): per-layer soft prefix of length 10, trained with the LM frozen to minimize KL( y_hat_{M+N} || y_{T+N} ) where y_hat is the patched-run distribution with teacher-forced subsequent tokens (Eqs. 10-11); gradients flow through the full LM (not a prefix-MLP).
- Main models trained on N = 1 objective; appendix shows N=1 training generalizes to N=2,3 but training on N=2/3 is worse at N=1.

## Models
GPT-J-6B (28 layers, d=4096, vocab 50,400).

## Datasets
The Pile samples. Train: 100,000 token positions (avg context 518); 10,000 of these for learned-prompt training. Test: 1,000 positions (avg context 535). Restricted to positions where GPT-J's next-token prediction is correct. Bigram baseline from 900,000 Pile documents.

## Probe design
Single-token, single-layer input; linear maps (one per layer x N in {0,1,2,3}, so 28x4 per type); learned soft prompt per layer. No pooling, no temporal memory.

## Metrics
Precision@k (k=1,5,10) of the probe's top token vs the model's actual top-k output at T+N; Surprisal (−log p under GPT-J of the probe's top token).

## Key numbers (Table 2, best layer)
| Method | N=0 | N=1 | N=2 | N=3 |
|---|---|---|---|---|
| Learned prompt acc | 97.0 | 48.4 | 43.7 | 46.9 |
| Fixed prompt acc | 97.0 | 20.8 | 30.0 | 36.5 |
| Linear->hidden acc | 98.0 | 29.2 | 19.0 | 15.8 |
| Linear->vocab acc | 85.7 | 27.5 | 19.4 | 14.7 |
| Learned surprisal | 0.6 | 4.5 | 4.4 | 3.9 |
| Linear->hidden surprisal | 0.8 | 14.1 | 13.2 | 13.1 |
- Decay with horizon: linear probes decay monotonically (29 -> 19 -> 16%); learned prompt roughly flat 44-48% across N=1..3. Bigram baseline 20.1% at N=1.
- Layer: future-token (N>=1) accuracy peaks at middle layers (~layer 14) whereas N=0 peaks at the last layer.
- Learned prompt beats best baseline by ~25 points P@1/5/10 on average.
- Calibration: N=1 accuracy 26/57/77/95% for model-confidence bins 0-30/30-60/60-90/90-100%.
- Named-entity subset: 44/42/37% for N=1,2,3 (future info not limited to multi-token entities).
- Table 3 (layer 14, N=1): learned prompt 23-52% across token categories vs linear 12-29%.

## Code / data
https://future.baulab.info

## Limitations
Only GPT-J-6B; 100k training positions; horizons only up to 4 tokens; test set filtered to correct-prediction positions; no RNN/non-autoregressive baselines.

## Relevance to observer/forecasting hypothesis
- Evidence that (a) linear decoders from one state decay quickly with horizon even at N=1..3, and (b) a richer nonlinear decoder that reuses LM computation (soft-prompt + patching, i.e., an Activation-Oracle/Patchscope-like verbalizer) recovers far more future information and decays less. This is the strongest version of the "direct verbalizer" baseline; the observer must be compared against such a decoder, not just linear probes.
- Middle layers carry the most future information -> read observer inputs from mid layers.
- Target choice: predicting future *hidden states* (HS) vs vocab are comparable for linear maps; supports using compact latent targets of future windows (rather than tokens) for the observer's auxiliary loss.
- Only token-level horizons <=4; says nothing about 100-2048-token horizons — a gap the hypothesis targets.
- Confidence-binned accuracy is a useful calibration-style analysis to replicate for hazard predictions.
