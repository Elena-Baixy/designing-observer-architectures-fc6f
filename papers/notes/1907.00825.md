# 1907.00825 — Time-to-Event Prediction with Neural Networks and Cox Regression (Cox-Time, pycox)
Kvamme, Borgan, Scheel (Univ. Oslo), JMLR 20 (2019). Read depth: MEDIUM (main text, App. C sims, App. D DeepHit).

## Research question
Can Cox regression be extended with neural networks (non-linear relative risk, and non-proportional / time-dependent relative risk) while remaining scalable to large data via minibatch SGD? Which methods give the best discrimination AND calibration?

## Method
Survival basics: S(t) = exp[-H(t)], H(t) = int_0^t h(s) ds. Observed T = min(T*, C*), D = 1{T = T*}.
Full likelihood (2):  L = prod_i f(T_i|x_i)^{D_i} S(T_i|x_i)^{1-D_i} = prod_i h(T_i|x_i)^{D_i} exp[-H(T_i|x_i)].

Cox PH (3): h(t|x) = h_0(t) exp[g(x)], g(x) = beta^T x (no intercept).
Cox partial likelihood, Breslow ties (4):  L_cox = prod_i ( exp[g(x_i)] / sum_{j in R_i} exp[g(x_j)] )^{D_i}
Negative partial log-likelihood loss (5):  loss = sum_i D_i log( sum_{j in R_i} exp[g(x_j) - g(x_i)] )
  R_i = at-risk set at T_i (includes i).
Breslow baseline (6):  H0_hat(t) = sum_{T_i <= t} dH0(T_i),  dH0(T_i) = D_i / sum_{j in R_i} exp[g_hat(x_j)].

Case-control (nested case-control) SGD approximation — sampled risk set R~_i of fixed size, always containing i (weights w_i drop out of gradients):
  (7)  L = prod_i ( exp[g(x_i)] / (w_i sum_{j in R~_i} exp[g(x_j)]) )^{D_i}
  (8)  loss = (1/n) sum_{i: D_i=1} log( sum_{j in R~_i} exp[g(x_j) - g(x_i)] ),  n = #events
  (9)  one control:  loss = (1/n) sum_{i: D_i=1} log(1 + exp[g(x_j) - g(x_i)]),  j in R_i \ {i}
       (range (0, log 2]; log 2 = 0.693 for constant g; batch-size independent.)
  New controls resampled every iteration, sampled with replacement.
Penalty for non-linear g (10):  penalty = lambda sum_{i: D_i=1} sum_{j in R~_i} |g(x_j)|.
Cox-MLP (CC) = g(x) an MLP trained with (8); Cox-MLP (DeepSurv) = MLP trained with (5) restricted to batch.

Cox-Time (non-proportional) (11): h(t|x) = h_0(t) exp[g(t, x)], time fed as an input covariate.
  (12) loss = (1/n) sum_{i: D_i=1} log( sum_{j in R~_i} exp[g(T_i, x_j) - g(T_i, x_i)] ) + penalty (10) with g(T_i,x_j).
  Note g(t,x)=a(t,x)+b(t): b(t) cancels, so baseline h_0 still estimated non-parametrically:
  (13) dH0(T_i) = D_i / sum_{j in R_i} exp[g_hat(T_i, x_j)];  H_hat(t|x) = sum_{T_i<=t} dH0(T_i) exp[g_hat(T_i, x)].
  Prediction: compute baseline on a random training subset (controls time-grid resolution); S_hat = exp(-H_hat).
  Complexity: O(n |R~|) = O(n) vs O(n^2) with full risk sets.

DeepHit (App. D, baseline): softmax over discrete grid tau_0<...<tau_m, y_j(x) = P(T* = tau_j | x), S_hat(tau_j|x) = 1 - sum_{k<=j} y_k(x).
  loss_L = - sum_i [ D_i log y_{e_i}(x_i) + (1 - D_i) log S_hat(T_i|x_i) ]
  loss_rank (D.1) = sum_{i,j} D_i 1{T_i < T_j} exp( (S_hat(T_i|x_i) - S_hat(T_i|x_j)) / sigma )
  (D.2) loss = alpha loss_L + (1 - alpha) loss_rank.

## Evaluation metrics (exact)
- Time-dependent concordance (Antolini 2005) (14): C^td = P{ S_hat(T_i|x_i) < S_hat(T_i|x_j) | T_i < T_j, D_i = 1 }, with Ishwaran et al. (2008, Sec 5.1 step 3) tie handling so x-independent predictions give 0.5. Equals Harrell's C for PH models.
- IPCW Brier score (Graf 1999) (15):
  BS(t) = (1/N) sum_i [ S_hat(t|x_i)^2 1{T_i <= t, D_i = 1} / G_hat(T_i)  +  (1 - S_hat(t|x_i))^2 1{T_i > t} / G_hat(t) ],
  G_hat = Kaplan-Meier estimate of censoring survival P(C* > t); assumes independent censoring.
- Integrated Brier score (16): IBS = 1/(t2 - t1) int_{t1}^{t2} BS(s) ds (numerical, 100 grid points over test-set duration span were sufficient).
- IPCW binomial log-likelihood (17):
  BLL(t) = (1/N) sum_i [ log(1 - S_hat(t|x_i)) 1{T_i <= t, D_i = 1} / G_hat(T_i) + log(S_hat(t|x_i)) 1{T_i > t} / G_hat(t) ];
  IBLL = 1/(t2 - t1) int BLL(s) ds. (Closer to 0 better for IBS and IBLL.)

## Datasets
SUPPORT (8,873; 14 covariates; 32% censored), METABRIC (1,904; 9; 42%), Rotterdam & GBSG (2,232; 7; 43%), FLCHAIN (6,524; 8; 70%) — from DeepSurv package / R survival (WHAS dropped: it is actually a case-control set with duplicates). KKBox churn (WSDM 2017 Kaggle): train 1,786,333 / test 661,748 / val 198,665, 28% censored, 15 covariates. All available via pycox. No HF datasets.

## Models / training
MLPs, equal width per layer, ReLU, batch norm, dropout, AdamWR (cycle doubling), decoupled weight decay, early stopping; 300 random hyperparameter configs per fold, 5-fold CV for small sets. KKBox best: Cox-MLP(DeepSurv) 6x256 drop .1; Cox-MLP(CC) 6x128; Cox-Time 8x256; DeepHit 6x512 (alpha .001, sigma .5). Baselines: classical Cox (lifelines), RSF, DeepHit.

## Key numbers
- Simulations: 1, 2, 4, 8 sampled controls converge at the same rate; Cox-SGD estimates match classical Cox for n >= 1,000; MLL diff ~0.1% even at n=100 with 1 control -> 1 control used thereafter.
- C^td (SUPPORT/METABRIC/RotGBSG/FLCHAIN): Cox-Time .629/.662/.677/.790; DeepHit .642/.675/.670/.792; Cox-MLP(CC) .613/.643/.669/.793; DeepSurv .611/.636/.674/.790; classical Cox .598/.628/.666/.790; RSF(C^td) .634/.652/.669/.786.
- IBS: Cox-Time .212/.172/.169/.102 (best on 3/4); DeepHit .223/.184/.178/.120 (worst). IBLL: Cox-Time -.613/-.511/-.502/-.432; DeepHit -.637/-.539/-.524/-.487.
- KKBox (median of 5 fits) C^td/IBS/IBLL: Cox-Time .861/.107/-.334 (best IBS, IBLL); DeepHit .888/.147/-.489 (best C^td, worst calibration); RSF(C^td) .870/.111/-.352; DeepSurv .841/.111/-.349; Cox-MLP(CC) .844/.119/-.379; Cox-SGD linear .816/.127/-.406.
- Key lesson: tuning on concordance pushes DeepHit's alpha toward the ranking loss -> great discrimination, poor calibration. Proportional NN Cox models unstable on large data.

## Code
https://github.com/havakv/pycox (PyTorch; implements CoxTime, CoxCC, DeepSurv, DeepHit, plus EvalSurv with C^td/IBS/IBLL and datasets).

## Limitations
Cox-Time prediction is expensive (needs g(T_i,x) at all baseline times; Breslow quadratic) — mitigated by subsampling; no time-dependent covariates/dynamic prediction/competing risks (future work); penalty needed for identifiability; independent-censoring assumption in IPCW metrics.

## Relevance to observer/forecasting hypothesis
- Evaluation protocol to adopt verbatim: report C^td, IBS and IBLL (IPCW, KM censoring estimate G_hat) of the observer's predicted S(t|activations at prefix p), where t = tokens-ahead (1..2048). Also report BS(t) curves vs lead distance t (like Fig. 4) — this directly tests "gain grows with lead distance". Use pycox EvalSurv.
- Censoring in the LLM setting: response ends (EOS) or max-horizon reached without event -> censored at min(remaining length, 2048). Note censoring by response length is likely NOT independent of the event (long answers may be more/less likely to turn unsafe); IPCW with KM G_hat assumes independence — consider covariate-dependent G (Gerds et al. 2012) or report results restricted to responses with full 2048-token follow-up.
- Loss options for the hazard head: (a) discrete-time hazard NLL (Nnet-survival / logistic-hazard, preferred, per-example minibatchable); (b) DeepHit PMF NLL (avoid heavy ranking-loss weight — hurts calibration); (c) Cox-Time with case-control sampling (continuous-time, tokens-ahead as input covariate; one control per event suffices) — good if continuous token-level event times matter.
- Warning for the comparison: pick hyperparameters on a calibration-aware criterion (IBLL/IBS or the NLL itself), not C^td alone.
- Survival-curve clustering (K-means on S(tau)) could summarize "trajectory types" of responses (e.g. early-unsafe vs late-drift).
- Note: dynamic prediction (re-predicting as more tokens are observed — exactly the observer's setting with memory) is listed as future work, not addressed here.
