# 2606.02609 — Building Better Activation Oracles

Bauer*, De Schamphelaere*, Karvonen, Luick, Nanda (MATS 10.0; UCL Gatsby, Ghent, Hamburg). arXiv v2, 4 Jun 2026. Short paper (8 pp + appendix, 14 pp total). All pages read.

## Research question
The original AO (Karvonen et al. 2025, 2512.15674) hallucinates, is vague, and is confounded by text inversion (answering by reconstructing surrounding text). Which changes to the AO training recipe reduce hallucination/vagueness and improve capability, and how should AOs be evaluated (AObench)?

## Architecture (exact)
- Same AO framework as Karvonen et al.: LoRA fine-tuned copy of the target model, placeholder tokens, **additive norm-matched injection after the second transformer layer** (h' = h + α·||h||·v/||v||). Their change: injection strength scale α. "Natural" ≈ √2× vs **2.0×** (best; AObench +0.417 → +0.435; hallucination score 79% → 85%). NLA-style replacement of the token embedding with a fixed scalar was "significantly worse" on Qwen3-8B (no formal ablation).
- **Multi-layer input**: source layers — original AO used random choice of 25/50/75% depth (layer 18 of Qwen3-8B's 36 = 50%). Single-layer sweep peaks at **layer 22 (62%)**; feeding **5 contiguous layers 21–25** is best (largest gains on model-diffing). Recommendation: ~65% depth if single layer.
- **Positions**: random subset of available positions from long CoT inputs (vs Karvonen's contiguous-n/single). Hallucinations decrease ~linearly with number of positions fed. AObench reported at context window ≥ 20 tokens; backtracking task: final token only 1.26/5, last 5 tokens 1.54, 20: 1.94, 50: 2.10, 200: 2.17, full: 2.16 vs black-box full-text baseline ≈1.95.

## Base / target model
Qwen3-8B (all experiments; layers 21–25 of 36).

## Training data
- **New conversational dataset** (replaces LatentQA/SPQA): Sonnet 4.6 receives a target-model CoT rollout, splits it into prefix/suffix, writes a question about the **suffix** that is hard to answer from prefix text but plausibly answerable from prefix activations. AO input = prefix activations + question; target = answer about suffix. HF: `ceselder/cot-oracle-convqa-chunked-sonnet`. Corpus disproportionately math.
- **On-policy past/future-lens**: next/previous-token prediction on the target model's own CoT rollouts instead of FineWeb.
- Classification tasks retained from original recipe.
- Narrow post-training on Ivanova et al. 2026 "hard CoT interp tasks" matched but never exceeded linear probes. DPO and GRPO (rubric: swap test, specificity, insight, not-wrong, instruction-following) were unstable / mixed; not adopted.

## Hyperparameters
All ablation runs exactly **50M training tokens**, lr **1e-5** (steering-2.0× run uses lr 3e-5), seeds 7/13/137 (n=2–3). LoRA rank/alpha not restated — inherit Karvonen recipe (r64, α128) — authors warn changing lr/rank/alpha destabilizes. Most eval uplift visible after 10% of training. Keep ≥10% mixed data per stage to avoid catastrophic forgetting. GPU hours not reported.

## Evaluation: AObench (open-sourced, "cot-oracle")
Tasks: Activation Sensitivity ("Not Just Reading Tokens": same tokens, different upstream contexts), Hallucination ("Not Obviously Wrong"), Missing Information (SimpleBench-style), Sycophancy (Scruples), Taboo, PersonaQA/Identify Persona (system prompt), **MMLU Prediction** (predict answer model would give if interrupted mid-reasoning), Number Prediction, Vagueness/Response Specificity, Domain Confusion, **Backtracking** (predict whether model is about to revise its line of reasoning). LLM judges; chance-adjusted scores. Hallucination score = normalized avg of Not-Obviously-Wrong, Domain, Missing-Info, Number.

## Key numbers
Ablation ladder (chance-adjusted AObench mean): Karvonen baseline +0.244 → conversational swap +0.310 → + multi-layer [21..25] +0.366 → + on-policy lens +0.417 → + steering 2.0× **+0.435**. Isolated: layer 22 alone +0.275; layers 21–25 +0.298; on-policy lens alone +0.274. Hallucination 68.8% → 84.6% (monotone after first step); vagueness 0.076 → 0.205.
Eval practice: Use ROC-AUC over Yes/No logit margin, not accuracy (sycophancy-from-CoT: original AO 0.50 acc vs 0.83 AUC; MLAO 0.60/0.85). Consensus sampling (k=10, agreement ≥0.8) on Taboo: 46.6% raw → 94.3% precision at 19.4% coverage (PR-AUC 0.874).
Footnote 5: a text-only baseline (same model given the full context instead of activations, trained on the same objective) performed similarly in an early run — a warning that AOs may not beat a matched text/probe baseline.

## Limitations
Marginal capability gains ("quality of life" improvements mainly); still hallucinates often; in many settings reading the CoT gives the same insight; checkpoints undertrained (50M vs 65M tokens); LLM-judge noise and prompt sensitivity; on-policy ablation confounded with conversational data (both on-policy CoT); single model (Qwen3-8B); math-heavy corpus; never beat linear probes on narrow tasks.

## Relevance to observer/forecasting hypothesis
- **Most forward-looking AO work so far, but short horizon.** The conversational dataset explicitly trains AOs to answer questions about the *future suffix* of a CoT from *prefix* activations — conceptually a forecasting objective. AObench includes Backtracking ("about to revise reasoning") and MMLU Prediction (eventual answer). Horizon is unspecified/implicit (CoT suffix length, typically tens–hundreds of tokens of math reasoning); no evaluation of horizon dependence, no 100s–2048-token time-to-event analysis, no safety-onset forecasting.
- Strong, current **direct-verbalizer baseline**: Qwen3-8B, layers 21–25 (5-layer multi-layer AO), 2× injection, ≥20–50 positions. For a fair comparison: fine-tune this checkpoint on our forecasting labels with the same budget as the observer.
- Important lessons for our experimental design:
  1. Report **AUC from Yes/No logit margin**; AOs are badly calibrated at fixed thresholds — supports adding a calibrated hazard head (and evaluating with Brier/ECE/C-index).
  2. **Context window matters**: AO with 1 position badly underperforms; give the baseline ≥50 positions (or full prefix) to avoid a strawman.
  3. **Linear probes are a ceiling for narrow AO fine-tuning** — include a linear/MLP probe baseline on the same activations and labels; the observer must beat probes too.
  4. A **text-only model with the full prefix** may match AOs (footnote 5) — include a text-only forecaster baseline.
  5. Multi-layer (~60–70% depth) input helps; observer should also read ~65% depth / multiple layers.
- Gap the observer fills: AOs are stateless per-query with no memory beyond what is injected, no multi-timescale latent prediction, no explicit time-to-event distribution.
