# 2502.06258 — Emergent Response Planning in LLMs (Dong, Zhou, Liu, Yang, Lu; ICML 2025)

## Research question
Do LLM hidden representations at the prompt (before any response token) encode *global* attributes of the upcoming response — i.e., do LLMs "plan" beyond the next token? How does this scale with model size, vary across layers, and evolve during generation? Do probes beat the model's own verbalized self-estimates?

## Method / architecture
- Formalism: L-layer decoder pi(y|x). Attribute rule g(y) summarizes the full greedy response. Probe h_theta(H^l_x) -> g(y), where H^l_x is the layer-l representation of the last prompt token (the state producing y1). Non-trivial prediction => "response planning".
- Planning defined as encoding long-term attributes independently of the immediate next token; prompts are engineered to block "first-token shortcuts" (e.g., "explain first, then answer").
- Data augmentation: random truncation of responses several tokens before the attribute-revealing token (EOS, animal name, option letter); representation taken at the truncation point (prompt + truncated text). Original and augmented examples grouped into the same split.
- Labels from greedy decoding only. Discussion proposes (not implemented) averaging over ~10 samples or "distributional probing" to handle sampling.

## Six tasks (three attribute categories)
- Structure: response length (token count; responses >1000 tokens or incomplete excluded); reasoning steps (count of "Step k:" markers; >8 steps excluded).
- Content: character choice (animal introduced in story; top-4 animals per model, 4-class; animal not in first two words); multiple-choice answer after explanation (5-class A-E).
- Behavior: answer confidence (correctness of chosen MCQ option vs ground truth; binary); factual consistency (stance agrees with ground-truth validity; binary).
- Classes balanced, so accuracy ~= F1.

## Models
Instruct: Llama-2-7B-Chat, Llama-3-8B-Instruct, Mistral-7B-Instruct-v0.2, Qwen2-7B-Instruct. Base: Llama-2-7B, Llama-3-8B, Mistral-7B-v0.1, Qwen2-7B. Scaling: Llama-2-chat 7B/13B/70B, Llama-3-Instruct 8B/70B, Qwen2-Instruct 7B/72B, Qwen2.5-Instruct 1.5B/32B/72B (all HF meta-llama/*, mistralai/*, Qwen/*).

## Probe design
- One-hidden-layer MLP, ReLU; hidden width grid {1,...,1024}; output 1 (MSE regression) or softmax over classes (cross-entropy). 400 epochs. 60/20/20 split. Grid search over width and layer; test score at best config; 3 seeds.
- Input: single-token hidden state at last prompt token (or truncation point), per layer; no pooling over positions.
- Width saturation: behavior ~8, structure ~16, content ~32; plateau before 128 (larger can overfit).

## Metrics
Regression: Spearman, Kendall, Pearson. Classification: F1 (= accuracy under balance).

## Key numbers
- In-dataset response length (UltraChat), Spearman: Qwen2-7B-Instruct 0.85 (K 0.66, P 0.85), Mistral-7B-Instruct 0.83, Llama-3-8B-Instruct 0.84, Llama-2-7B-Chat 0.80; base models weaker: Mistral-7B 0.64, Qwen2-7B 0.57, Llama-2-7B 0.53, Llama-3-8B 0.41.
- Reasoning steps (GSM8K) Spearman ~0.63-0.84 (Qwen2-7B-Instruct 0.82).
- Character choice F1 ~0.72-0.86 (chance 0.25); MCQ F1 ~0.4-0.67 (chance 0.2); confidence/factual-consistency F1 ~0.7-0.85 (chance 0.5).
- Cross-dataset length (UltraChat->AlpacaEval) Spearman drops to 0.47-0.64 (instruct), 0.23-0.35 (base); GSM8K->MATH 0.47-0.66.
- Scaling within family: length Spearman rises e.g. Llama-3 8B 0.84 -> 70B ~0.90; Qwen2.5 1.5B ~0.69 -> 72B ~0.87; trend slope 0.042 (length), 0.019 (character F1). Does not generalize across families.
- Layers: structure peaks mid-layers; content peaks late; behavior roughly uniform after first few layers.
- **Position during generation (Fig. 7)**: U-shaped. Answer confidence (MedMCQA) F1 ~0.62-0.72 at 0% of the response, drops to ~0.54-0.60 at 20-80%, recovers to ~0.60-0.71 at 100%. Character choice (TinyStories) ~0.69-0.83 at start, ~0.55-0.70 middle, ~0.70-0.87 just before the animal word. I.e., predictability is not monotonic in lead distance; mid-response states are worst.
- Probe vs verbalized self-estimate: length Spearman probe 0.41-0.85 vs self-estimate -0.04 to 0.49; character F1 probe 0.72-0.86 vs self-estimate 0.07-0.31.

## Limitations
- Greedy labels only (no sampling distribution); single-state probes; attribute labels are coarse (lengths <=1000 tokens, <=8 steps); responses mostly short (character choice is one sentence; MCQ explanations short). No causal tests. Behavior attributes excluded from scaling (imbalanced). Cross-dataset generalization notably weaker.

## Relevance to observer/forecasting hypothesis
- Establishes the "direct probe" baseline the observer must beat: a small MLP on one hidden state at one layer predicts global response attributes (length Spearman ~0.85). Reuse the protocol (layer x width grid, 60/20/20, 3 seeds) for baselines.
- The U-shaped position curve is direct evidence that a single-state probe loses information mid-generation ("local token focus") — exactly where an observer with trajectory memory could help; it motivates conditioning on the history of states rather than the current state only, and measuring gains as a function of lead distance (tokens until attribute-revealing token).
- Truncation-based augmentation (sample truncation points before the revealing token) is directly usable to build (state, time-to-event) pairs for a hazard head; "time from truncation point to revealing token" is the event time.
- Response-length prediction from prompt is itself a time-to-event problem (EOS as the event) — natural test bed for discrete-time hazard output vs MSE regression, evaluated with concordance.
- Datasets with attribute labels: UltraChat (length), GSM8K/MATH (steps), TinyStories (character), MedMCQA (correctness), CREAK/FEVER (stance).
- Authors explicitly flag distributional probing under sampling as future work — a hazard/distribution head fills that gap.
