# 2511.05963 — Next-Latent Prediction Transformers Learn Compact World Models (NextLat)
Teoh, Tomar, Ahn, Hu, Pearce, Sharma, Krishnamurthy, Islam, Lamb, Langford (Microsoft Research). arXiv v4, Jun 2026. Read depth: DEEP (main text + App. A–F).

## Research question
Transformers attend to the whole history, so nothing pushes them to compress it into a compact, recurrent-style latent state. Can an auxiliary *self-supervised latent-space prediction* objective (predict your own next hidden state from the current hidden state and the next token) turn transformer hidden states into **belief states** (sufficient statistics of history for the future) without changing the architecture, inference, or parallel training?

## Method / architecture
- Three parts: a transformer θ producing final-layer hidden states h_t (pre-logit), an output head p_θ, and a **latent dynamics model p_ψ** (3-layer MLP with GELU; input = LayerNorm(concat(h_t, emb(X_{t+1}))); residual delta output ĥ_{t+1} = f_ψ(h_t, X_{t+1}) + h_t) (App. C, Fig. 11).
- Theorem 3.2: if next-token consistency p_θ(X_{t+1}|h_t)=P(X_{t+1}|X_{1:t}) **and** transition consistency p_ψ(h_{t+1}|h_t,X_{t+1})=P(h_{t+1}|X_{1:t+1}) both hold, then h_t is a belief state (proof by backward induction, App. B). This already holds for d=1; multi-step d>1 only gives a richer signal.
- Multi-step recursive rollout: ĥ_{t+d} = p_ψ(h_t, X_{t+1:t+d}) using teacher-forced tokens.
- At inference p_ψ is optional. It can be used for **variable-length self-speculative decoding** (recursive latent rollouts beyond the training horizon d).

### Exact losses
- Next-token: L_next-token(θ) = E_{t<T}[ −log p_θ(X_{t+1} | h_t) ]
- Next-hidden regression (Eq. 3): L_next-h(θ,ψ;d) = E_t[ (1/d) Σ_{i=1..d} SmoothL1( sg[h_{t+i}], ĥ_{t+i} ) ], where sg = stop-gradient on the target (prevents collapse; the ablation shows it helps).
- KL self-distillation (Eq. 4): L_KL(θ,ψ;d) = E_t[ (1/d) Σ_{i=1..d} D_KL( p_θ^sg(·|sg[h_{t+i}]) || p_θ^sg(·|ĥ_{t+i}) ) ], with the output head frozen (gradients only reach p_ψ).
- Total (Eq. 5): L_NextLat = L_next-token + λ_next-h·L_next-h + λ_KL·L_KL. Typical values: λ_next-h ∈ {1,2}, λ_KL ∈ {0.1,1}; λ_KL=1 and λ_next-h=1 work broadly (Table 5).
- Masking: token losses are masked on prompt tokens, but L_next-h is NOT masked on context tokens (so belief states form during context processing). Losses that cross document boundaries are masked when sequences are packed.
- Baseline losses reviewed (App. A): BST (Eq. 6, see 2410.23506 note). JTP: L = E[−log p(X_{t+1}|h_t) − λ_MTP (1/d) Σ_i log p(X_{t+i+1} | Fetch(h_t, X_{t+1:t+i}))]. JTP only gives belief states if the process is k-observable with d+1 ≥ k (Prop. A.2).

## Models
All are trained from scratch (nanoGPT-style decoders). Manhattan: 48L/384d/8 heads (88M). Countdown: 12L/768d. Path-Star: 12L/384d. TinyStories: 8L/768d. A5: 2L/512d. FineWeb-Edu: 1.3B params (22L/2048d/16 heads), 100B tokens, GPT-2 tokenizer (vocab 50,257), seq len 1024, AdamW, WSD schedule. p_ψ MLP hidden widths range from 384 to 6528. Baselines: GPT (NTP), MTP (Gloeckle et al.), JTP (Ahn et al. 2025), BST.

## Datasets
- Manhattan random-walk taxi traversals (Vafa et al. 2024): 91M sequences, 4.7B tokens.
- Countdown: 500k generated problems (targets 10–100, 10% of targets held out as OOD), 10k test, 8 pause tokens.
- Path-Star graphs G_{2,10}, G_{5,5}, G_{7,7}: 200k training samples, N=100, 20k test.
- TinyStories: 2.7M stories, 1k-token vocabulary, length 256. (No HF ID is given in the paper. The commonly used one is roneneldan/TinyStories; this is my addition.)
- A5 word problem: 1M unique 12-token sequences for training; about 100k 36-token sequences for testing.
- FineWeb-Edu 100B tokens (Penedo et al. 2024). No HF ID is given in the paper (commonly HuggingFaceFW/fineweb-edu; my addition). Speculative-decoding evaluation uses Wikipedia, BookCorpusOpen (huggingface.co/datasets/bookcorpusopen is cited), Stack-Edu, and OpenWebMath: 1024 prompts × 512 tokens each, with 512-token continuations.

## Probe design
- TinyStories future-token probing: model frozen; **20 independent linear (one-layer) probes, one per token offset k=1..20**, each predicting token X_{t+k} from the final-layer hidden state; trained for 20k steps with the pretraining hyperparameters. Metric: probe CE loss difference vs. GPT.
- Hidden-state choices: GPT/NextLat use final-layer output. JTP uses the state just before the Fetch head's attention. MTP uses the shared trunk output. BST uses the forward encoder's final layer.
- Effective latent rank = exp(Shannon entropy of normalized singular values) over a 256×256-token hidden-state matrix (Roy & Vetterli 2007).

## Metrics
Manhattan: next-token test, valid-trajectory %, sequence compression, effective latent rank, detour robustness. Countdown accuracy and per-equation validity. Path-Star solve rate. Probe CE vs. token offset. Perplexity plus zero-shot accuracy (LM-Eval-Harness: Wiki, LAMBADA, PIQA, HellaSwag, Wino, ARC-e/c, SIQA, SciQ). Speculative decoding speedup and accepted tokens per draft. Cumulative draft acceptance vs. draft position.

## Key numbers
- Manhattan (Table 1): NextLat valid trajectories 98.7% (GPT 97.0, MTP 98.1, JTP 97.1). Sequence compression 0.71 (GPT 0.65, JTP 0.32). Effective rank 52.7 vs. GPT 160.1 (more than 3× more compact). Detour robustness 95% (GPT 85%).
- Countdown (Fig. 4): GPT 33.1, BST 42.3. MTP d=1/4/8: 39.2/49.7/57.3. JTP: 39.0/49.4/55.0. **NextLat: 54.8/57.6/58.7**. At d=1, final-equation validity is 54.8% vs. 42.3% for the next-best method.
- Path-Star: NextLat solves close to 100% on all three graphs. BST fails on G_{7,7}. GPT, MTP, and JTP mostly fail.
- **Horizon decay (TinyStories, Fig. 8/16):** MTP/JTP/BST hurt offset-1 loss, and their probe advantage over GPT *shrinks quickly as the offset grows*. NextLat matches GPT at offset 1 and keeps the largest gain up to offset 20 (roughly −0.3 to −0.4 nats vs. GPT at offsets 10–20; read from the figure). Gains peak around offsets 2–4 (≈ −0.6 to −0.9) and decay with offset for all methods, but least for NextLat. Ablation (Fig. 12): at d=1, Smooth L1 alone gives the best 20-ahead probe. At d=8, KL+SmoothL1 is best. Stop-gradients on both the target and the head are best at all offsets (Fig. 14). KL beats CE as the auxiliary term at d=1; the gap is marginal at d=8 (Fig. 13).
- 1.3B FineWeb-Edu (Table 2/6): perplexity 10.83 (d=1) vs. GPT 10.52, so NTP is preserved better than MTP/JTP (10.90–11.29). Average accuracy for NextLat d=2 is 59.21 vs. GPT 58.82, a modest and inconsistent gain.
- Speculative decoding (Table 3): NextLat d=2 gives 3.21× on Wikipedia with 4.59 accepted tokens per draft, vs. MTP d=2 at 1.68×/1.72 and JTP d=2 at 1.88×/1.84. Up to 3.3× overall. Fully accepted drafts still occur at length 10 (Fig. 9b), but cumulative acceptance decays roughly geometrically with draft position (≈0.85 at position 4 down to ≈0.1 at position 10 for d=2).
- A5 (Fig. 10): the co-trained latent dynamics MLP (2.62M params) reaches >95% accuracy at length 36 after training on length 12, while the transformers (both GPT and NextLat) collapse beyond 12 tokens.
- Cost (Table 4): NextLat d=1 trains at 3.09 it/s, the same as GPT. BST runs at 0.89 it/s even with 10% pair subsampling.

## Limitations (stated)
p_ψ is only a simple MLP; its bottleneck width is not studied. Loss design choices (sg, KL, Smooth L1) come from small ablations, and it is unclear whether d>1 or KL matter at scale. Smooth L1 rises during LR cooldown (unexplained), and the method is sensitive to the optimizer (Muon vs. AdamW). Largest model is 1.3B, from scratch only; post-hoc finetuning of pretrained LLMs is not tested. Horizons evaluated are short (probe offsets ≤ 20 tokens, drafts ≤ 10 tokens). No adaptive draft length.

## Relevance to observer/forecasting hypothesis
- **Directly borrowable latent-dynamics loss:** in the observer, treat the frozen LLM's activations (or a compressed summary z_t from them) as the "state". Train an observer transition p_ψ(z_t, x_{t+1}) → ẑ_{t+1} with Smooth L1 against stop-gradient targets, plus a frozen-head KL term. For a frozen LLM, the analogue is to regress future (pooled) activations with sg targets and use the LLM's own unembedding / an attribute head as the frozen "output head" for the KL term. NextLat shows latent-space targets give denser signal than one-hot labels. This supports the hypothesis that predicting compact future latent summaries helps beyond direct label supervision.
- **Belief-state theory:** the one-step transition-consistency + output-consistency sufficiency argument (Thm 3.2) justifies an observer memory state that is trained to be recursively predictive. This is the theoretical case for component (a) memory and (b) future-latent prediction vs. a stateless probe.
- **Horizon-decay evidence:** per-offset linear probes show that token-space MTP objectives encode only short-horizon information. Latent prediction keeps information further ahead, but all methods still decay with offset, and the tested horizons (≤20 tokens) are far below the 100–2048-token target. Multi-scale *window-summary* targets (not per-token) will be needed. The paper itself suggests "hierarchical belief states spanning multiple layers or tokens" as future work.
- **Evaluation recipe to reuse:** a probe per lead distance (one probe per offset) on a frozen representation, reported as Δ-loss vs. a baseline representation. Effective rank as a compactness diagnostic for the observer state. Cumulative acceptance vs. horizon as a decay curve.
- Caveats: NextLat modifies the base model during pretraining. The observer setting freezes the LLM, so only the "co-trained RNN" view (the A5 result: the dynamics model generalizes beyond the transformer) transfers directly. That view supports a separate recurrent observer trained on frozen-transformer states.
