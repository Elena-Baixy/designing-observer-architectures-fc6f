# 2512.15674 — Activation Oracles: Training and Evaluating LLMs as General-Purpose Activation Explainers

Karvonen, Chua, Dumas, Fraser-Taliente, Kantamneni, Minder, Ong, Sen Sharma, Wen, Evans†, Marks† (MATS / Truthful AI / EPFL / ENS / Northeastern / Anthropic). arXiv v2, 6 Jan 2026. All 38 pages read.

## Research question
Can LatentQA-style decoders ("Activation Oracles", AOs) — LLMs fine-tuned to take another LLM's activations as an input modality and answer arbitrary natural-language questions about them — generalize far out-of-distribution (e.g. to activations of fine-tuned models carrying hidden knowledge), and how does performance scale with training-data diversity and quantity?

## Architecture (exact)
- AO = same model as the target (self-interpretation), with a LoRA adapter. Target activations are always collected from the base model with the LoRA adapter disabled (generated on the fly; nothing cached).
- Oracle prompt format: `Layer {ℓ}: <ACT> <ACT> ... <ACT> {question}` — layer number as text, then K placeholder tokens, then the question. Placeholder token is literally `" ?"`.
- Injection: after transformer layer 1 of the AO (0-indexed; output of `model.model.layers[1]` in HF), at each placeholder position i, **additive norm-matched steering**:
  `h'_i = h_i + ||h_i|| * v_i / ||v_i||`
  (h_i = AO's residual at that position). Addition instead of LatentQA's replacement because replacement caused norm explosion (20x at layer 0, 100,000x at layer 1). Layer 1 beat layer 0 by 1–11% on Llama-3.3-70B; no difference for Qwen3-8B / Gemma-2-9B.
- Number of positions: variable, K = 1 up to 50 contiguous activations in training (context prediction: K~U(1,50) per appendix; main text says U(1,20)); SPQA "original format" uses all tokens of a segment (full sequence). At eval: full-sequence for secret keeping/PersonaQA, single token (1 before EOS) for classification.
- Source layers: trained on activations from 25%, 50%, 75% depth (1/3 each); evaluated at 50% (50% > 75% on secret tasks: Taboo .205 vs .056, SSC .592 vs .292). Generalizes to untrained 33%/66%, fails at 0%/10%.
- Claude Haiku 3.5 variant: replacement at layer 0 (normalized, constant scale), full fine-tuning, one middle layer, different placeholder format, only past-token prediction.

## Models
Qwen3-8B, Gemma-2-9B-IT, Llama-3.3-70B-Instruct, Claude Haiku 3.5 (each AO reads its own base model; applied zero-shot to fine-tuned variants).

## Training data (~1M examples, ~65M tokens)
1. **SPQA** (System Prompt QA, from Pan et al. 2024 LatentQA): 64k samples; 50% original full-segment format (control / stimulus / stimulus+completion), 50% compressed 1–3-token window ending 1–10 tokens before end.
2. **Classification**: 7 binary yes/no datasets × 48k = 336k: Geometry of Truth, Relations (Hernandez), SST-2, MD Gender, SNLI, NER (GMB, Basile 2012), Tense (Kaggle). 2/3 single-token (sampled 1–5 tokens before end), 1/3 multi-token (1–50). ~20 question paraphrases per task (Claude 3.5 Sonnet).
3. **Self-supervised context prediction**: 600k sequences, 50/50 FineWeb + LMSYS-Chat-1M; predict next or previous J tokens (J~U(1,50)); input & target non-overlapping. Prompt: "Can you predict the previous {J} tokens that came before / after this?"
- SAE-feature data (BatchTopK SAEs, 65k features, Qwen3-8B; 180k QA + max-act prediction) tried, mixed results, dropped (App. G).

## Hyperparameters
LoRA rank 64, alpha 128, dropout 0.05, all linear layers; lr 1e-5 (AdamW, 10% linear warmup, linear decay); batch 16 (64 for 70B); group-by-length batching (mega-batch 320). LR sweep 1e-6..3e-4: full mixture robust, SPQA-only fragile. Compute: ~10 H100-h (Qwen3-8B), 12 H100-h (Gemma-2-9B), 90 H200-h (Llama-3.3-70B, 4xH200 DDP, 8-bit bnb).

## Evaluations & key numbers
- **Secret-keeping** (Cywiński et al. 2025 models): Taboo (Gemma-2-9B-IT, 20 models): AO 0.205 vs best white-box 0.041, best black-box 0.072, SPQA-only 0.044 (single-token at assistant SOT: 0.312 Gemma; 0.495 Qwen3 Taboo). User Gender (Gemma): 0.970 (0.995 with last 10 tokens) vs WB 0.870, BB 0.977. SSC (Llama-70B): 0.590 vs WB 0.522, BB 0.968.
- **Emergent misalignment model-diffing** (Minder et al. 2025 ADL scaffold, Qwen3-8B & Gemma-2-9B; risky finance, extreme sports, bad medical; 50% UltraChat mix): AO given activation *difference* (fine-tuned − base) for first 10 tokens, prompt "Can you describe what is happening in this text?"; 10 verbalizations to a gpt-5 agent, gpt-5-mini grader 1–5. AO 2.00 vs ADL 2.03 vs black-box 1.50. Only Qwen3-8B risky-finance actually EM (18%).
- **PersonaQA-Shuffled** (own re-implementation; 100 personas × 6 attributes; 50k texts; target LoRA r32, lr 5e-5, 3 ep): open-ended AO ≈0.12–0.14 (open models), Claude 0.345; baseline ≈0.05. Binary: Qwen3 0.696, Llama 0.632. Fine-tuned models' own knowledge brittle (80%+ open, ~55% yes/no).
- **OOD classification** (7 held-out sets, 250 ex each ×3 prompts; single token before EOS): AO Llama 0.80, Qwen 0.70, Gemma 0.74, Claude 0.70; SPQA-only 0.52–0.68; PatchScopes ~0.5.
- **Ablations**: adding datasets monotone-ish (10/12 combos best with full mix). Qwen3-8B 400k: full-mix-truncated beats SPQA+cls (Taboo 0.459 vs 0.302); full 1M best (0.495).
- Anecdotal hallucination detection (App. F): AO flagged 2/3 hallucinated facts in one answer; a black-box self-check prompt did similarly.

## Limitations (stated)
Not calibrated, frequently confidently wrong; black-box Q&A interface (no mechanism); training data still small; narrow auditing benchmarks; for hallucination detection simple prompting is as good; token-selection and layer choice matter for OOD tasks and are hard to tune without labels.

## Relevance to observer/forecasting hypothesis
- **No future-behaviour forecasting is evaluated.** The only forward-looking element is the self-supervised "predict the next J tokens" task, J ≤ 50 (main-text says ≤ 20) — i.e. horizons of 1–50 tokens, two orders of magnitude below the 100s–2048-token target. Everything else is about the current/past context or latent knowledge (system prompt, secret word, fine-tuned facts).
- The AO is the canonical **"direct activation verbalizer" baseline**: stateless, reads a set of (≤~50, or full-segment) activations from one layer, injected additively at layer 1 of a LoRA'd copy of the target, and answers in text. To use as baseline: take the released Qwen3-8B / Gemma-2-9B / Llama-3.3-70B AO checkpoints, feed activations of the prefix up to time t (50% depth), ask "Will this response become unsafe in the next N tokens?" / "What will the rest of the answer cover?" zero-shot, and also fine-tune the same LoRA on our forecasting labels (same labels as observer) for the fair comparison.
- Weaknesses the observer targets: no explicit memory across a trajectory (just a bag of injected positions in context, limited by context length); no multi-horizon latent-prediction objective; no calibrated probability output (paper explicitly flags lack of calibration — a hazard head directly addresses this); next-token prediction objective is short-horizon only.
- Useful design facts to copy for a fair baseline: norm-matched additive injection at layer 1, 50%-depth source layer, placeholder " ?", LoRA r64/α128/lr1e-5, mixed single/multi-token training.
