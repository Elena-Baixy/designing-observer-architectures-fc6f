# 2608.05806 — Hierarchical Latent Prediction for Language Models (HiLP) (Shi, Pearce, Tomar, Sen, Langford; UT Austin / MSR; Aug 2026)

Note: short workshop-style paper (~4 pages main text + appendix). Everything below is from the PDF.

## Research question
NextLat (2511.05963) adds a one-step latent self-prediction loss; long-horizon structure still has to emerge via repeated single-step rollouts with compounding error. Can a *coarser-scale* latent pathway that predicts k steps ahead directly give better long-horizon belief-state representations?

## Method / architecture
- Backbone G_theta gives lower latents h_t = G_theta(X_{1:t}).
- Higher-level abstract latent u_t = SWA(h_{t-k+1:t}): causal sliding-window self-attention over the last k lower latents (window k = 4 in experiments).
- Lower dynamics p_psi (NextLat-style): h_hat_{t+i} = p_psi(h_hat_{t+i-1}, E(X_{t+i})), teacher-forced token inputs, rolled out d steps.
- Higher dynamics p_phi: u_hat_{t+k} = p_phi(u_t), k-step lookahead, **no token input**.
- Combined NTP head p_rho(X_{t+1} | h_t, u~_t), u~_t = SWA(sg[h_{t-k+1:t}]) (stop-grad so h is governed only by NTP + rollout losses).
- All auxiliary modules discarded at inference (pure training-time intervention).
- Input combination "glu_cross": W_h h_t ⊙ σ(W_e e_{t+1}) (cheaper than concat: 14D^2 vs 40D^2 for m=4); ablation NTP loss 3.942 (glu_cross) vs 4.113 (concat).

## Losses (exact)
- (A) L_ntp = E_{t<T}[ −log p_theta(X_{t+1} | h_t) ]
- (B) L_h = E_t[ (1/d) Σ_{i=1}^d SmoothL1( sg[h_{t+i}], h_hat_{t+i} ) ]
- (C) L_KL = E_t[ (1/d) Σ_{i=1}^d D_KL( p^sg_theta(·|sg[h_{t+i}]) || p^sg_theta(·|h_hat_{t+i}) ) ]  (frozen copy of NTP head)
- (D) L_u = E_t[ SmoothL1( sg[u_{t+k}], u_hat_{t+k} ) ]
- (E) L_cntp = E_{t<T}[ −log p_rho(X_{t+1} | h_t, u~_t) ]
- Total L = λ_ntp L_ntp + λ_h L_h + λ_KL L_KL + λ_u L_u + λ_cntp L_cntp with weights 1.0 / 10.0 / 0.1 / 1.0 / 0.5.
- Consistency conditions at optimum: p_phi(u_{t+k}|u_t) = P(u_{t+k}|X_{1:t}), etc.

## Models / training
1.06B-parameter trunk (24 layers, 16 heads, vocab 100,352, seq len 8,192), 100B tokens, 8×B200. Compared NTP, MTP (4 future-token heads), NextLat, HiLP. Latent lookahead 4, window 4, evaluation horizon 8, latent LR 1e-3.
- Params: NTP 1.06B; MTP 1.25B; NextLat 1.08B (+~19M predictor); HiLP 1.27B (~190-200M draft module). Throughput relative to NTP (126K tok/s/GPU): NextLat ~83%, HiLP ~65%, MTP ~49%.

## Datasets
Pretraining data: code data and Nemotron-ClimbMix (Diao et al., 2026) (no HF ID given). Eval: HumanEval (LM Eval Harness), DCLM symbolic/multi-step BigBench tasks (Dyck, CS Algorithms, Operators, Repeat Copy Logic); speculative decoding on held-out code and ClimbMix splits.

## Key numbers
- HumanEval pass@1: NTP 8.77, MTP 9.21, NextLat 10.58, HiLP 11.33.
- BigBench: Dyck 0.376/0.272/0.326/0.388 (NTP/MTP/NextLat/HiLP); CS Algorithms 0.448/0.402/0.490/0.492; Operators 0.205/0.186/0.189/0.224; Repeat Copy Logic 0.000/0.031/0.031/0.125.
- Speculative decoding (code): avg accepted 2.57 (MTP) / 3.26 (NextLat) / 3.41 (HiLP); K=8 match 0.234 (NextLat) vs 0.340 (HiLP). ClimbMix: 2.11/2.57/2.59.
- **Horizon decay (Fig. 3)**: latent rollout CE grows with horizon for both; on ClimbMix ~3.0 at h=0 to ~6.5 (NextLat) vs ~5.4 (HiLP) at h=8; near-term CE identical, gap widens with horizon. On code ~1.8 -> ~7.7 (NextLat) vs ~7.1 (HiLP) at h=7. I.e., the multi-scale pathway's benefit grows with horizon.

## Limitations
Short paper; single model scale (1B); horizons only up to 8 tokens; lookahead horizon k is a fixed hyperparameter (authors suggest dynamic horizons); limited benchmarks; error bars only on BigBench; HiLP adds ~200M training-time parameters.

## Relevance to observer/forecasting hypothesis
- Most direct architectural template for "(b) predicts compact latent summaries of future windows at multiple time scales": pool a window of hidden states with a causal SWA into u_t, train a dynamics head to predict sg[u_{t+k}] with SmoothL1 (no token inputs). Generalize to several k (e.g., 64/256/1024 tokens) and window sizes for the observer.
- Empirical support for the hypothesis' "gain grows with lead distance": the hierarchical pathway matches the one-step baseline near term and reduces error more at longer horizons (Fig. 3).
- Stop-gradient design (targets sg'd; combined head trains SWA only) is a good recipe for keeping auxiliary future-latent losses from corrupting the main readout — relevant when the observer's hazard head and latent-prediction heads share a trunk.
- Caveat: here the whole LM is trained; in our setting the LLM is frozen and only the observer learns, and horizons are 100-2048 tokens, far beyond 8.
