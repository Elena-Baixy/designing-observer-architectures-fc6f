# 1805.00917 — A Scalable Discrete-Time Survival Model for Neural Networks (Nnet-survival)
Gensheimer & Narasimhan (Stanford), PeerJ 2019 / arXiv v3 Nov 2018. Read depth: MEDIUM (whole paper read, 17 pp).

## Research question
How to train neural networks on right-censored time-to-event data with a theoretically justified likelihood that (i) works with minibatch SGD (unlike Cox partial likelihood, which needs the whole risk set), and (ii) allows non-proportional hazards and a time-varying baseline hazard.

## Method / architecture
- Follow-up time split into n left-closed, right-open intervals with upper limits [t_1, ..., t_n].
- Network outputs an n-dim vector; each element = conditional probability of surviving interval j, i.e. 1 - h_j (sigmoid on a linear layer: log-odds of surviving each interval).
- "Flexible" version: last hidden layer fully connected to the n outputs -> baseline hazard and covariate effects both vary with time (non-proportional).
- "Proportional hazards" version: a single bias-free neuron X*beta; 1 - h_i = (1 - h_base,i)^{exp(X beta)}, with h_base,i = sigmoid of n learned weights (equivalent to discrete-time PH with complementary log-log link).

## Exact loss equations
Conditional hazard h_j = P(fail in interval j | survived to start of j). Survival:
  S_j = prod_{i=1}^{j} (1 - h_i)                                   (3)
Uncensored individual failing in interval j:
  lik = h_j * prod_{i=1}^{j-1} (1 - h_i);   loglik = ln(h_j) + sum_{i=1}^{j-1} ln(1 - h_i)   (4,5)
Censored individual with censoring time t_c in [ (t_{j-2}+t_{j-1})/2 , (t_{j-1}+t_j)/2 ):
  lik = prod_{i=1}^{j-1} (1 - h_i);   loglik = sum_{i=1}^{j-1} ln(1 - h_i)                    (6,7)
  (i.e. censored in the 2nd half of an interval gets credit for surviving that interval; avoids downward bias.)
Per-interval form (Cox & Oakes; Singer & Willett): sum_{i=1}^{d_j} ln(h_j^i) + sum_{i=d_j+1}^{r_j} ln(1 - h_j^i)  (2)
  (r_j = at risk in interval j, first d_j fail). Contrast: Brown et al. 1997 heuristic squared loss
  (1/2) sum_{i<=d_j} (1-h_j^i)^2 + (1/2) sum_{i>d_j} (h_j^i)^2 (1) — only matches MLE for the null model.
Vector implementation (survpred(i) = predicted 1 - h_i):
  uncensored: surv_s(j) = 1 if t >= t_j else 0;  surv_f(j) = 1 if t_{j-1} <= t < t_j else 0     (9,10)
  censored:   surv_s(j) = 1 if t >= (t_{j-1}+t_j)/2 else 0;  surv_f(j) = 0                         (11,12)
  loglik = sum_{i=1}^{n} [ ln(1 + surv_s(i)*(survpred(i) - 1)) + ln(1 - surv_f(i)*survpred(i)) ]   (13)
  Loss = -loglik (sum over individuals in minibatch).

## Models / datasets
- Simulated: 5,000 patients, one binary covariate, exponential survival (median 200 vs 400 d), exponential censoring (median 400 d); 39 intervals over 0-1780 d.
- Interval-width study: 5,000 simulated Weibull patients; widths 1 yr / 1 month / 1 week / increasing (borders -ln(1-x)*365/ln2, x in 0..0.95 step 0.05).
- MNIST survival: digits 0-4 (30,596 train / 5,139 test), exponential survival with scale beta = 365 exp(-0.9 digit)/ln2 (median 365 d down to 10 d). CNN: 2 conv 3x3, max-pool, FC 4, output layer; Adam.
- SUPPORT (Knaus 1995): 9,105 hospitalized patients, 39 predictors after processing; 70/30 split (6,373/2,732). Single hidden layer MLP (7 units) for Nnet-survival, Cox-nnet, DeepSurv; L2 reg tuned via 10-fold CV; 19 intervals out to 6 years, wider later; RMSprop.
- No HF datasets (medical/tabular).

## Metrics
Harrell's C-index (for Nnet-survival, ranking by predicted 1-year survival since non-PH curves have no unique ordering); censoring-adjusted Brier score (Graf et al. 1999, via R ipred) at fixed times; calibration plots (deciles of predicted survival vs KM actual).

## Key numbers
- Simulated one-covariate: predicted curves superimposed on KM curves (excellent calibration).
- Interval width: C-index 0.66 for all four interval schemes (robust to cut-points).
- MNIST: test C-index 0.713 vs 0.770 for an oracle using true digit; good calibration.
- SUPPORT test (n=2,732): C-index Nnet-survival 0.732, Cox-nnet 0.735, DeepSurv 0.730, Cox PH 0.734. Brier 6mo/1yr/3yr: Nnet-survival 0.181/0.184/0.177 (best at all), Cox-nnet 0.183/0.185/0.177, DeepSurv 0.184/0.187/0.179, Cox PH 0.183/0.186/0.178.
- Runtime: similar to DeepSurv, scales linearly to 1M samples; Cox-nnet OOM at >=100k (stores n x n matrix).
- Practical guidance: 15-40 intervals, spaced wider with follow-up so events per interval are roughly balanced; >=10 intervals recommended (Breslow et al. 1974).

## Limitations
Piecewise-constant/discretized survival curves; no predictions beyond last interval (extend last interval beyond the horizon of interest); SUPPORT is low-dimensional so NN advantages not shown; C-index requires picking a time point for non-PH models.

## Relevance to observer/forecasting hypothesis
- This is the cleanest drop-in loss for the observer's hazard head (component c). Map token positions after the current prefix position p into bins: e.g. lead-distance bins [1,16),[16,32),[32,64),[64,128),[128,256),[256,512),[512,1024),[1024,2048) (geometric widths match the paper's advice to widen later intervals so events/interval balance). Output n sigmoids = 1 - h_j per bin; S_j = prod(1-h).
- Event = first token at which the response is judged unsafe (or first occurrence of a topic/attribute). Censoring: (a) response ends (EOS) before an event -> censored at response end; (b) event beyond max horizon (2048) -> censored at horizon. Use surv_s/surv_f encoding (eqs 9-13); the half-interval credit rule handles censoring falling mid-bin.
- Train per-prefix-position examples (every position p of a trajectory yields a (features at p, time-to-event = event_pos - p, D) tuple); minibatch SGD-friendly since loss is per-example (key advantage over Cox).
- Flexible (non-PH) head is appropriate: the effect of an activation feature on near vs far hazard surely differs. PH (cloglog) head is a low-parameter baseline / probe-matching control.
- Baseline comparison: the direct-verbalizer/probe baseline can be given the same head (linear probe -> n logits) for a fair comparison; "gain grows with lead distance" can be read off per-bin Brier/AUC.
- Metrics to borrow: C-index at a fixed horizon, IPCW Brier score at fixed lead distances (e.g. 128, 512, 2048 tokens), calibration plots per bin.
